# Persistent Project Rules & Instructions

## 1. Always Utilize Saved Skills
- **Mandatory Skill Utilization**: Always proactively check and invoke existing saved skills in the Antigravity ecosystem (including Phaser Game Engine, Matter.js Physics, GSAP Animations, Howler.js Audio, Frontend UI Engineering, Game Design, Architecture, and Testing) whenever building or modifying features in this project.
- **High-Standard Game & UI Development**:
  - Use rich aesthetics, glassmorphism, responsive design, and smooth animations (GSAP/CSS transitions).
  - Use modular audio architecture (`Howler.js` / Web Audio API) with sound effects for interactions.
  - Implement full multiplayer synchronization, client-safe state masking, and robust fallback logic (AI bots / local pass & play).
  - Maintain type safety, proper Suspense boundaries for Next.js App Router, and clean project architecture.

## 2. Automatic GitHub Commit & Push
- **Mandatory Git Sync**: After completing any code changes, feature additions, or bug fixes, always stage (`git add .`), commit with descriptive conventional commit messages, and push immediately to GitHub (`origin main`). Ensure the repository is kept synchronized and up to date at all times.
